# Project 8: Network Proxy

The final project is listed as Network Proxy in the course syllabus and wiki sidebar. The available command-line driver describes a proxy mode that multiplexes incoming TCP connections between servers.

## Contents

- `src/sans_proxy.c`: the original `tcp_proxy` starter function, which currently returns without performing any forwarding.
- `tests/p8_tests.c`: the original placeholder that reports that Project 8 tests are not implemented.

## Current State

Only starter code is available for this project. No working proxy implementation or functional test suite was found in the repository. The uploaded wiki contains the Project 8 title and link, but not its assignment page, so detailed requirements cannot be confirmed.
